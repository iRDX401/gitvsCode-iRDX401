Data Structures:

1) Strings: Each items in it is a character. Cannot change or are immutable.
> Strings are immutable - cannot be changed. You will have to create a new variable if you want to change anything in this.
> Strings are ordered and indexed - each character has a specific position starting from index 0.
> Can loop through the strings
> They are homogeneous - Can be used for Slicing, concatenation & Formatting.

2) Lists: They are ordered, editable collections. Can be removed, added and replaced with any values. Like a shelve.
lst = [1,2,3,4,5,6,7]

3) Tuples: Ordering of the items is not allowed. Data should stay fixed. like coordinates of a location in a map or settings
tpls = (1,2,4,7,5,9,10)

4) Dictonaries: Simething like a phone book One Employee ID (Key) have multiple attributed date to that person (Values).
phone_book = {
    "e01" : {"Rahul Das": 883462343478},
    "e02" : {"Hello D": 9934575435}
}

5) Sets: its like guests list for an event. There are no duplicates allowed.
guest_list = {"iRDX", "Bob", "Marley", "Amir"}
